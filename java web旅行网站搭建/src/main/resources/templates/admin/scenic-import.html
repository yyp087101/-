导入说明

当前模式：本地上传

图片存储：上传后的文件会写入 /uploads/scenic/ 目录并通过站内地址访问。

字段要求：景点名称必填，其余信息可按需要补充。

导入结果：景点会以写入数据库，在景点管理列表中可继续编辑。

如果上传新图片，系统会优先使用本地图片地址；未提供图片时会回退到默认封面。
